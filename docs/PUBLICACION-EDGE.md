# Publicación en Microsoft Edge Add-ons — Infocivil Ebook DGN

Panel: https://partner.microsoft.com/dashboard/microsoftedge/overview
(cuenta cncivil.sytec@outlook.com) → **Crear extensión nueva**.

## 1. Paquetes

Mismo ZIP que Chrome (`infocivil-ebook-dgn-0.1.12.zip`): Edge acepta Manifest V3
de Chrome sin cambios.

## 2. Disponibilidad

- **Visibilidad:** Oculta (solo con el enlace directo), como "No listado" en Chrome.
- **Mercados:** todos, o solo Argentina.

## 3. Propiedades

- **Categoría:** Productividad.
- **¿Accede, recopila o transmite información personal?** Sí: lee documentos
  judiciales que pueden contener datos personales (los guarda solo en el
  navegador). Requiere URL de privacidad:
  `https://matiasardizzone-rgb.github.io/-Infocivil-ebook-DGN-extension/privacidad-dgn.html`
- **Sitio web:** `https://github.com/matiasardizzone-rgb/-Infocivil-ebook-DGN-extension`
- **Contacto de soporte:** el mismo que Infocivil Ebook.
- **Clasificación:** sin contenido para adultos.

- **Descripción corta:** el resumen del manifest.
